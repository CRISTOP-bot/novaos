# M2.5 — User memory access

M2.5 añade una frontera validada entre memoria user y el kernel.

## Permisos

`paging_translate_info()` devuelve `present`, `user`, `writable` y `executable`. En x86 las páginas presentes son legibles; no existe un bit separado de lectura. `nova_copy_from_user()` exige que todas las páginas del rango estén presentes y marcadas `USER`, además de validar límites y overflow.

## Copia

`nova_copy_from_user()` obtiene el root de `nova_process_current()`, valida el rango mediante `paging_root_translate_info()`, cambia temporalmente a ese CR3 solo si es necesario, copia byte por byte al buffer kernel y restaura el root anterior.

## SYS_WRITE

`fd == 1` es stdout y `NOVA_WRITE_MAX` limita la copia a 128 bytes. El buffer de Ring 3 se copia a un array kernel antes de llamar a `console_write()`.

## Fuera de alcance

No se implementan ELF, `SYS_READ`, filesystem nuevo, libc, shell ni política W^X completa.
