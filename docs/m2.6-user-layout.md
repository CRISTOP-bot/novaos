# M2.6 — User-space layout and initial stack

M2.6 define regiones user explícitas sobre los roots de paging de M2.4.

## Regiones

`nova_user_region` posee su rango virtual, flags lógicos, lista de páginas físicas y enlace al address space. `nova_user_region_map()` asigna páginas PMM y usa `paging_root_map_page()`; `unmap` desmapea, libera las páginas y elimina metadata.

Flags lógicos:

- `READ`: presente (x86 no tiene bit read separado);
- `WRITE`: entrada writable;
- `EXEC`: ausencia de NX.

## Stack

El stack inicial ocupa 8 páginas (32 KiB) en:

```text
0x00007fff00000000 .. 0x00007fff00008000
```

Tiene `USER | READ | WRITE | NX`. `initial_rsp` apunta a 16 bytes debajo del extremo superior. No hay crecimiento automático.

## Ownership

Las regiones poseen sus páginas hoja y su metadata. El address space posee la lista de regiones. Al destruir un proceso, `nova_user_region_cleanup()` libera páginas user y metadata antes de destruir las tablas privadas; nunca toca mappings o tablas kernel compartidas.

No hay ELF, mmap genérico ni allocator user.
