# M2.7 — ELF64 userspace loader

M2.7 carga un ELF64 `ET_EXEC` estático embebido en el kernel para probar el pipeline completo sin añadir filesystem.

## Validación

Se aceptan únicamente `ELFCLASS64`, little-endian, versión actual, `ET_EXEC` y `EM_X86_64`. Se comprueban límites del archivo, `PT_LOAD`, `filesz <= memsz`, overflow, rango user y entrada ejecutable.

Cada segmento se convierte en una `nova_user_region`; se asignan páginas mediante el PMM y se aplican `PF_R/PF_W/PF_X`. El loader copia `p_filesz` y deja en cero el BSS restante. La entrada debe estar dentro de una región ejecutable.

## Ejecución temporal

`userspace/hello.S` es un programa freestanding que usa únicamente `SYS_WRITE` y `SYS_EXIT`. El ELF se enlaza a `0x400000`, se convierte en un objeto binario y se enlaza temporalmente dentro del kernel. El loader crea proceso, address space, regiones, stack, `RIP` y `RSP`; después el kernel activa el proceso y llama a `ring3_enter()` con ese contexto.

Esto no es `init`, shell ni soporte de filesystem. El ELF embebido se eliminará o sustituirá cuando exista una fuente de archivos userspace.
