# M2.8 — Userspace bootstrap / initramfs

M2.8 reemplaza el ELF embebido directamente en el kernel por una imagen initramfs temporal enlazada como objeto binario.

## Formato

`build/initramfs.img` contiene:

```text
nova_initramfs_header
nova_initramfs_entry { path[64], offset, size }
file data
```

El único archivo inicial es `/init`. El formato comprueba magic, versión, cantidad, tamaño del header, bounds y `offset + size` antes de usar cualquier dato.

## Ruta

```text
initramfs.img → VFS /init → vfs_read → nova_process_create_from_elf → Ring 3
```

El kernel no recibe el ELF como variable C independiente: recibe el objeto `initramfs.img`, lo monta en el VFS y lee `/init` desde ese VFS.

`userspace/init.S` es un ELF64 `ET_EXEC` freestanding que usa `SYS_WRITE` y `SYS_EXIT`. No hay shell, init persistente, libc, filesystem nuevo ni soporte `exec`.
