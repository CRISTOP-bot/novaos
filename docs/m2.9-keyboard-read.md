# M2.9 — Teclado PS/2 y SYS_READ

Se añadió un driver i8042/PS/2 mínimo para scancodes Set 1 en IRQ1 (vector 33), con remapeo del PIC 8259. La tabla cubre letras, números, espacio, tab, Enter y Backspace; otras teclas se ignoran. El buffer es circular de 127 caracteres útiles y descarta caracteres cuando está lleno.

`SYS_READ` usa `fd=0`, devuelve inmediatamente los caracteres disponibles y devuelve cero si no hay datos. No implementa bloqueo ni scheduler de espera. Rechaza otros fds, longitudes cero o mayores a 128 y buffers userspace inválidos.

`nova_copy_to_user()` comparte la validación por página de `copy_from_user`, y además exige bits `present`, `user` y `writable`.

`/init` contiene el programa de prueba de lectura; `/bin/readtest` se incluye en el initramfs para la siguiente etapa. El smoke test de CI valida compilación, inicialización y self-tests, pero no inyecta teclas físicas en QEMU: la interacción teclado real queda **NOT VERIFIED**.
